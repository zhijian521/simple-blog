## 缘起

玩梦幻久了，有些账总是算不清：这个月到底赚了多少，几件装备各花了多少，想练的角色技能点到几级了。

表格能记，但记不细。物品得按当前物价估值，点卡要按在线时长摊到每个号头上，装备有十二个格子。

所以写了一个只属于自己的本地手账。

![梦幻养老助手总览](images/mh-tool-overview.webp)

## 它是什么

一个 Windows 桌面应用，Electron + Vue + TypeScript，八个页面。

| 页面 | 用途 |
|------|------|
| 总览 | 收益、账号、目标汇总，14 天趋势 |
| 收益 | 物品速记按物价估值，在线计时分摊点卡，按天分账 |
| 账号 | 人民币与梦幻币分账，记录筛选与 CSV 导出 |
| 目标 | 养成目标自动累计，存钱与装备目标手动记进度 |
| 装备 | 三套方案，12 个格子，仓库与截图识别 |
| 角色 | 档案、技能、修炼、门派模板 |
| 物价 | 两级分类，卡片式行情与价格流水 |
| 设置 | 三档外观，JSON 备份导入导出，检查更新 |

![收益页：物品速记与在线计时](images/mh-tool-income.webp)

## 两条原则

数据只在本机。不登录、不上传，断网也能用。账本存在 `%APPDATA%` 下，不在安装目录，所以升级不会丢；换机器导出一份 JSON 就够。

麻烦事都藏在界面后面。截图识别放在独立子进程里跑，一次一张，超时就断——放主进程会把保存一起卡住。外链一律拦截，只能走白名单打开，界面上点不出意外的窗口。

## 装来用

需要 Node 22.12 以上。

```bash
git clone https://github.com/zhijian521/mh-toolbox.git
cd mh-toolbox
npm ci
npm run dev
```

不写代码的话，到 Releases 下载安装版或便携版即可，两种装法共用同一份数据。
