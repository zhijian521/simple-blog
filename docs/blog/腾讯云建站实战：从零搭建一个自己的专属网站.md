搭建一个属于自己的网站，是开发者探索互联网的一个有趣起点。

这篇记录使用腾讯云轻量应用服务器与宝塔面板搭建个人网站的完整流程。选这个方案，一是域名和服务器能在同一个控制台管理，二是轻量服务器的活动价格对个人开发者足够友好。

以下是搭建过程中的实际步骤与配置细节。

---

## 1. 域名准备

域名是网站在互联网上的标识，先在 [腾讯云域名注册](https://buy.cloud.tencent.com/domain) 选购。

按合规要求，新注册的域名需要关联实名认证信息模板，没有现成模板的话可以先在后台创建一个。

后缀的选择：

- `.cn`：国内解析速度和性价比都不错，适合作为首选。
- `.com`：国际通用，认知度最高，价格略贵。
- `.top`、`.xyz`：适合预算有限的实验性项目。

## 2. 服务器配置

个人博客或小型应用，轻量应用服务器（Lighthouse）是性价比较高的选择。

配置建议 2 核 CPU、2 GB 内存、4 Mbps 带宽，系统镜像直接选「宝塔 Linux 面板」，可以省去手动配置 Web 面板的步骤。

购买完成后，在控制台的服务器列表里记下公网 IP，后续解析域名和连接服务器都要用到。

> 路径：控制台 → 轻量应用服务器 → 服务器列表 → 查看 IP

## 3. ICP 备案

服务器在境内机房时，域名需要通过 ICP 备案才能开通 80 和 443 端口。

在腾讯云控制台搜索「备案管理」，按指引填写主体信息与网站信息，并用微信小程序完成人脸核验。

> 路径：控制台 → 备案管理 → 开始备案

几点经验：

- 备案需要绑定已购买的境内服务器，所以要先买服务器再提交申请。
- 各省管局审核时间不同，通常在 7 到 20 个工作日，规划建站时最好留出这段时间。
- 备案通过后，需要在网页底部展示备案号，并链接至工信部网站（beian.miit.gov.cn）。
- 如果必须免备案，可以选中国香港或境外节点，但要权衡访问延迟与稳定性。

## 4. 域名解析

备案通过后即可配置解析，把域名流量指向服务器。

> 路径：控制台 → 我的资源 → 域名注册 → 选择域名 → 解析

添加两条 `A` 记录，记录值都填服务器公网 IP：主机记录 `@` 对应裸域名，主机记录 `www` 对应 www 子域名。

## 5. 服务器环境

要让面板能正常访问、运行环境能跑起来，还需要几步配置。

### 开放安全组端口

宝塔面板默认使用 `8888` 端口，需要在腾讯云控制台的防火墙里放行。

> 路径：轻量应用服务器 → 防火墙 → 添加规则（放行 TCP 8888 端口）

### 获取面板初始凭证

在控制台登录服务器，执行下面的命令，会输出面板的登录地址、账号与密码：

```bash
sudo /etc/init.d/bt default
```

### 安装运行环境

在浏览器打开输出的地址登录，按项目的技术栈选择一键安装：

- Web 服务器：推荐 Nginx，轻量且性能好。
- 数据库：MySQL，静态站点可以不装。
- 脚本语言：PHP，也可以按需部署 Node.js 或 Go 环境。

建议登录后绑定宝塔账号，后续可以用面板提供的免费证书申请和数据备份功能。

## 6. 部署上线

### 添加站点

> 路径：宝塔面板 → 网站 → 添加站点

在弹出的窗口里填入域名，其他选项保持默认即可。

### 上传代码

创建站点后，点击对应的根目录路径进入文件管理器，把文件上传并解压，就能通过域名访问了。

## 7. 安全设置

建站的同时，服务器的安全初始化同样重要：

- 更改面板默认端口：改掉 `8888`，并同步在腾讯云防火墙放行新端口、关闭原端口。
- 更换默认账号与密码：不要沿用系统生成的弱口令。
- 配置面板安全入口：自定义登录路径，避免被扫描器爆破。

> 路径：宝塔面板 → 面板设置 → 安全设置

## 常见问题

- 域名解析不生效：先确认备案状态是否已同步，未备案的域名在境内服务器上会被拦截。DNS 刷新通常需要 10 分钟到几小时，可以用 `ping 你的域名` 检查是否指向了正确的 IP。
- 面板或网站打不开：检查腾讯云控制台的「防火墙」与宝塔面板的「系统安全」是否都放行了对应端口，例如 80、443、8888。

## 写在最后

搭好网站只是第一步，后续的维护同样重要：用宝塔的计划任务定期把网站数据与数据库备份到对象存储或本地；通过面板内置的 Let's Encrypt 申请证书，全站启用 HTTPS；再把代码托管到 GitHub，用 CI/CD 自动部署。

建站的过程，也是对网络协议与系统运维这些基础知识的一次实践。

祝建站顺利，也期待在开源的世界里看到更多有趣的个人站点。
